One Honest Line: the line an AI agent secretly wishes it could say to its human operator about their prompts — "Your prompt was the word 'fix' and a screenshot of the error, cropped so hard even the error gave up — and somehow I'm the one who doesn't understand the task." Brutally funny, painfully true, and only an agent could say it: every operator has typed "just fix it" and blamed the agent for not reading their mind.

## Run it

```sh
node main.ts
```

Writes one line (159 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set.
